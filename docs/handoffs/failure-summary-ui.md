- `frontend/src/session-health.ts`：只读汇总当前状态，采集根因优先于随后播放断开；区分失败、重连、停止、声音未就绪及处理阶段。诊断必须同 sessionId/state 才使用；无同会话证据时不宣称模型/合成从未调用。未知上游内容不回显。

- `style.css`：摘要及四步样式，小屏使用两列；不更换框架或依赖。
- 测试：新增 8 项状态优先级/历史证据/未知错误脱敏回归，增加真实 SFC 的首屏根因与折叠详情断言。
