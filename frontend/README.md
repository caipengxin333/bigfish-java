# BigFish 前端与舞台

## 开发与验证

从仓库根目录分别运行 `./scripts/dev-backend.sh`、`./scripts/dev-frontend.sh`，脚本读取当前工作树 `runtime/worktree.env`。主集成目录端口为后端 18080、前端 15173；前端开发工作树仍为 18082/15175，按 runtime/worktree.env 隔离。

在 frontend 目录运行：

```sh
npm ci
npm test
npm run build
```

依赖版本保持基线不变。测试用 Node 内置 test runner（Node 22.12+ / 24），无需额外测试依赖。测试包含 HTTP 错误/超时、播放状态机、Web Audio 生命周期和 mock 配置并发保存。

## 模式和边界

- `/admin`、`/stage` 默认真实模式；显式选择 `?transport=mock` 才启用浏览器演示，不自动回退。
- 真实接口模式已接入 bootstrap/config/runtime/session/simulate/replay；当前 Java 数据源和回复默认 MOCK、声音为 300ms 测试音，页面明确标识。
- 已保存配置、表单草稿和运行生效版本分开。409/超时/网络失败保留草稿；读取最新版本后明确选择保留草稿或采用服务器内容。保留草稿是整份配置覆盖，不能自动合并不同字段。
- Mock 配置在此浏览器同源 localStorage 保存，通过 Web Locks 串行检查版本；演示运行状态仅在当前管理页内存中。停止演示通过 BroadcastChannel 通知同源 mock 舞台。
- 管理页不实例化 AudioContext。前端不提供供应商密钥输入，不访问供应商 API。

## 舞台

真实模式使用同源 `/ws/stage`。舞台“开始互动”先在点击调用链尝试解锁 AudioContext，再创建/接入后端会话与连接租约；只有目标 sessionId 一致、租约有效且音频 running 才发送 PLAYER_READY。声音被阻止时显示补救按钮，不重复创建会话。浏览器不维护待播放队列。

音频仅来自同源 `/api/v1/audio/{assetId}`，拒绝跳转、查询参数、片段、路径穿越和外源地址。assetId 接受字母、数字、下划线、连字符及一个扩展名点号。下载流限制 20 MiB，下载/解码整体限时 12 秒，音频最长 120 秒，这是浏览器防御上限；后端实际音频上限为 2 MiB / 25 秒，本地测试音为 300ms，STARTED 等待 5 秒，完成期限为实际音频时长加 5 秒、最多 30 秒。

STARTED 跟随音频时钟推进，不只依赖动画帧；COMPLETED 来自 source.onended，取消时先拆除 onended 防止误报。字幕只在 STARTED 后出现，嘴型由音频 RMS 驱动。普通标签隐藏保持连接，freeze/pagehide、停止、断线、租约到期仍清理；恢复可见时核对音频及会话。音频中断会断开以撤销服务端 ready，后续手动恢复。长期后台、系统休眠和 OBS 尚未验收。

页面实例独立 playerId。任务去重缓存最多 2048 项，保留至任务到期且至少 15 分钟；不会淘汰仍受保护的 ID，容量满则拒绝新连接。停止会话最多记录 128 个，达到容量后需刷新。缓存不跨刷新持久化，去重仍需后端保障。断线不自动重连/重播，“恢复播放”仅接回原本仍在运行的会话。

握手 payload 和会话绑定已由集成确认，见 `../docs/playback-protocol.md`；未启动会话时提示 NO_SESSION。

## 手动验收

1. 真实管理页开两个页面。A 保存配置后，B 用旧版本保存应显示 409、保留草稿；读取最新版本并核对后可再次保存。关闭本工作树后端再刷新，应显示加载失败，不声称已连接。
2. Mock 管理页启动演示后再保存配置，保存版本应变化、模拟生效版本保持原值。可展开“Mock 保存故障演练”检查超时与冲突提示。
3. Mock 舞台点击“开始互动”，展开本地演练区并“播放测试音”。检查 STARTED、4 秒测试音、COMPLETED，以及静音段嘴型归零。文本说明这是测试音，不是 TTS。
4. “重发上一任务”“发送过期任务”“发送旧会话任务”均不应重播。故障注入支持下载、解码、超时、取消、停止、断线与停止续租。
5. 打开两个舞台实例，第二个申请租约应拒绝并静音。普通标签切换不主动释放首个租约；关闭首个或明确仅断开本页后，第二个才可获取租约。
6. 开发服务下打开 `/tests/visual.html`，在页面加载后点击“重新检查横向溢出”。它提供 375px 管理页与两个独立舞台页面；不进入生产构建。

## 可插拔角色与素材来源

`src/stage/avatar.ts` 导出 `stageAvatarKey`，可在应用创建时 `app.provide(stageAvatarKey, YourAvatar)` 替换默认组件。渲染组件接受 `mouthLevel`（0..1）、`speaking`、`connected`；由舞台统一控制音频，组件不得自行播音。

默认 `PlaceholderAvatar.vue` 是为本项目手工编写的原创 SVG 鱼形角色；mock/stage.ts 的测试音为内存生成 PCM 正弦音。没有复制旧项目 Live2D 模型、纹理、声音、配置或第三方采集脚本。真实 Live2D SDK/模型需由集成窗口确认来源及许可证后再接入。

## 集成验收入口

管理页保存业务配置并选择本浏览器启动选项，再进入默认 `/stage` 点击“开始互动”。使用高级区的“模拟评论 / 模拟礼物 / 采集器连击回放”验证 MOCK 后端链路；DOUYIN 禁止模拟注入。管理页不发声。

启动选项仅保存三个白名单枚举于 `bigfish.browser.launch-options.v1`，同源页面通过 storage 事件同步，跨浏览器/跨端口不共享。加载和保存不会自动启动。启动结果不明确时只查询、不重发；停止超时明确显示后端未确认。额外公共字段和幂等操作 ID 属于后续提案，本轮未更改协议。
